# 🤖 Radha AI Chatbox

Radha AI Chatbox is a simple AI-style chatbot created as part of the CodeAlpha Cloud Computing Internship.

## ✨ Features

- 💬 Instant chatbot responses
- 🤖 Predefined conversational patterns
- ⌨️ Typing effect
- 🎨 Simple and user-friendly interface
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ▶️ How to Run

Open the `index.html` file in a web browser.
